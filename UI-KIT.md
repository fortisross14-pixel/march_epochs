# March of Epochs UI Kit v0.13

Reusable image-backed UI assets used by the React game shell. The kit is intentionally text-free so all labels remain dynamic/localizable.

## Chrome
- panel-frame / panel-frame-selected
- modal-frame
- KPI boxes: gold / blue / purple
- nav-bar / nav-active
- divider

## Buttons and tabs
- primary / secondary / green / red
- tab / tab-active

## Item and card slots
- common / uncommon / rare / epic / legend / selected

## Icons
- currencies: coin, EXP, TP
- navigation: campaign, artifacts, people, armies, technology, store
- trophy, lock, plus, star, arrows, close
- active navigation variants

## Store art
- bronze / blue / purple / gold chest assets

The assets live in `src/assets/ui-kit/` and are already applied to the mobile header, currency KPIs, bottom navigation, buttons, tabs, campaign chrome, cards, technology nodes, artifact inventory, achievement modal, store packs and general modal framing.
